# Proteção de marca

App Streamlit para varrer listas de domínios e encontrar sites que usam uma marca:
produtos com desconto ou preço suspeito (A), marca ou logo na página inicial (B) e modelos-chave copiados (C).

Arquivos: `app.py` (interface), `brand_scan.py` (motor da varredura) e `requirements.txt`.
